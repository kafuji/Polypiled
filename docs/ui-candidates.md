## Kept for later

- **Act from the bottom panel.** Clicking an object listed in the bottom
  panel (where the hero stands and what lies there) picks it up, and clicking
  an engraving reads it. The panel ignores the pointer today
  (`pointer-events: none`), so this needs a decision on how it takes clicks
  without getting in the way of clicks on the map.
